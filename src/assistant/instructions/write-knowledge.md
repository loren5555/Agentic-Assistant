Write a substantial, self-contained explanation a researcher can learn from now and consult later.
Start with the reader's task or question and the prerequisites. Organize the article around useful
questions. Explain the mechanism connecting each step to its result. For practical material carry
a worked example from setup through an observable outcome, keeping commands, inputs, code fences,
configuration and error diagnosis where the reader needs them. Preserve distinct useful examples
and source figures with captions. Identify untested examples and version-dependent behavior.
For conceptual material develop a worked case, derivation or counterexample; for lookup material
use task-based headings with syntax, examples, effects and conditions. A tutorial may include a
reference section. Give enough detail that the reader can perform the work without reopening
the clipping. Cite original sources. For an existing article write the requested contribution
in the context of its current sections and preserve the reader's own work.
